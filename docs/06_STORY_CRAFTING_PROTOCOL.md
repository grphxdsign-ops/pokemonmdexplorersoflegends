# Story Crafting Protocol

The project should not stall by asking the user for every small story choice.

## Default Mode

The assistant should craft story details autonomously whenever the choice is local, reversible, or mainly a matter of execution.

This includes:

- town names,
- dungeon names,
- minor NPCs,
- local customs,
- scene sequencing,
- cutscene staging,
- dialogue beats,
- clue placement,
- red herrings,
- optional quest hooks,
- side mission structures,
- non-final domain incident details,
- minor rival team behavior,
- PMDO implementation breakdowns.

When making these decisions, prefer:

- classic PMD emotional clarity,
- mystery-forward foreshadowing,
- simple but memorable domain identities,
- future PMDO implementability,
- clean cause-and-effect for Renown and story flags.

## Ask the User Only for True Questions

Consult the user when a choice changes canon direction, technical direction, or emotional identity.

Ask before changing:

- locked Domain Mantle species,
- major villain identities,
- major villain motives,
- protagonist death/resurrection structure,
- main ending structure,
- whether the partner is fixed or customizable,
- the next domain order when it affects pacing,
- Team Apex's final fate,
- release strategy or legal risk posture,
- PMDO versus another engine,
- core progression mechanics.

## Interview Cadence

Each story pass should end with no more than 3 to 5 questions.

Questions should be high-impact and easy to answer. Avoid asking for tiny flavor choices unless the user specifically wants to design them.

## Autonomous Story Pass Format

For each arc, create:

1. Purpose of the arc.
2. Setting.
3. Main conflict.
4. Antagonist or false antagonist.
5. Team Apex role.
6. Arcanine or villain-trio involvement.
7. Key dungeon sequence.
8. Ending state.
9. PMDO implementation notes.
10. True questions for the user.

## Current Autonomy Baseline

The assistant may assume:

- Storm Domain is the first suspicion arc, not a lesson arc.
- Dusknoir is innocent but easy to fear.
- Arcanine is actively staging public heroism.
- Zoroark is the main architect of false appearances.
- Houndoom prefers escalation and chaos.
- Team Apex can be ruthless without cheating in every arc.
- The partner's desperation should build slowly and should not start in Storm.
