# Local Build: The Playable Browser Game

Last updated: 2026-07-03

## What exists now

`game/` contains a complete, self-contained browser implementation of
**Pokemon Mystery Dungeon: Explorers of Legends** - no install, no engine download,
no ROM. It runs on any device with a browser (desktop or phone).

This supersedes the earlier PMDO plan (docs/01) as the *playable* build path: PMDO
requires installing a desktop C# application and generating a Quest package in its
dev mode, which was not possible in this environment and is not "open a link and
play" accessible. The PMDO documents remain valid as design source material - all
canon systems (Renown, hidden skill ranks, attribute points, moral drift, branching
endings) are implemented in this build.

## How to play

Option A - straight from the repo checkout:

1. Clone or download this repository to your device.
2. Open `game/index.html` in a browser (double-click works; no server needed).

Option B - host it (recommended for phones): enable GitHub Pages for this repo
(Settings → Pages → deploy from branch, root). Then play at the Pages URL - the
repo root `index.html` redirects into the game.

Controls:

- Move: arrow keys / WASD (hold for continuous movement; diagonals by combining)
- A (confirm/attack): Z, Enter, or Space
- B (cancel/menu back): X or Esc
- Menu: M or Tab - Wait a turn: `.` - Moves menu: Q
- Touch devices show an on-screen d-pad and A/B/MENU buttons automatically.

Saving: automatic at the town, plus manual save in the town menu. Saves live in
the browser's localStorage; the town menu can export/import a save code string
for moving between devices.

## Architecture

| Layer | Files | Notes |
| --- | --- | --- |
| Data | `game/data/data_*.js` | Generated by `tools/generate_data.mjs` from PokeAPI CSV dumps. All 1,025 species through Gen 9 (paradox included) + 155 mega/primal/regional/origin forms, level-up learnsets, moves with PMD-style ranges, type chart, exp tables. |
| Engine | `game/js/00-11,14` | Canvas renderer, PMD dungeon loop, Explorers of Sky damage formula, hub town, story player, systems, audio synth. |
| Content | `game/js/12_content_dungeons.js`, `13_content_story.js` | Dungeons/spawn pools and the full story campaign. |
| Tools | `tools/` | Data generator and content validator (`node tools/validate_content.mjs`). |

Sprites and portraits stream at runtime from PMDCollab **SpriteCollab**
(community-made, PMD-authentic art: https://sprites.pmdcollab.org). If offline,
the game draws colored placeholder sprites instead of failing. A local sprite
mirror can be pointed at via `window.EOL_SPRITE_BASE`.

## Fidelity to the series (see docs/06_PMD_SERIES_RESEARCH.md)

- 8-way grid, leader-clocked turns, allies/enemies act after the leader.
- Explorers of Sky damage formula `(A+P)*39168/65536 - D/2 + 50*ln(10*((A-D)/8+L+50)) - 311`
  with mainline powers rescaled to PMD's range; STAB 1.5x; type chart compressed
  to PMD's 1.4x / 0.7x / 0.5x.
- Belly on the leader only; Apples matter. Wind blows you out of overlong floors.
- Move ranges: front / line (10 tiles) / room / around / self / allies. 4 moves + PP,
  regular A-button attack, Elixirs restore PP.
- Recruitment on defeat by the leader's final blow, gated by species rate, level
  advantage, and (new) Charisma/Beast Handling skill ranks. Legendaries recruit
  only in the postgame (canon lock).
- Wipe penalty: lose carried money and half the bag - the Duskull Bank protects savings.
- Reviver Seeds auto-revive. Escape Orbs leave. Monster Houses ambush. Kecleon sells.
- Evolution at the Luminous Spring between dungeons (series style), with
  Evolution Crystals standing in for trade/item evolutions.
- Mega Evolution via Empowerment Seed during a dungeon (Rescue Team DX style),
  unlocked in the postgame.
- Speed is an accuracy/evasion stat, never turn order (canon lock, Super MD style).

## Scope decisions

- "Include every Pokemon except the 3 new starters": the dataset includes every
  species through National Dex #1025 (Gen 9, all paradox forms) plus megas and
  regional forms. The three starters of the not-yet-released next generation do
  not exist in any public dataset, so their exclusion is automatic; nothing from
  Gens 1-9 was removed.
- No ripped assets anywhere: sprites are community SpriteCollab art fetched at
  runtime, music/SFX are synthesized in WebAudio, tiles/UI are drawn in code.
  The repo distributes no ROMs and no official artwork (see legal notes in
  PROJECT_CONTEXT.md).
