# Explorers of Legends PMDO Quest

This is the PMDO Quest package for the first playable slice.

## Current Scope

- Prologue.
- Chapter 1.
- Starter quiz.
- Partner selection.
- One beginner dungeon.
- Arcanine rescue cutscene.
- First Renown reward.
- First Attribute Point reward.

Later domain arcs are intentionally out of scope until this slice is playable.
